# 🏥 Saúde Conectada

### IFAL Campus Benedito Bentes

> **Informação, comunicação e cuidado dentro do IFAL.**

O **Saúde Conectada** é uma plataforma digital desenvolvida para o **IFAL Campus Benedito Bentes**, com o objetivo de centralizar informações, facilitar o acesso aos serviços de apoio e saúde do campus e melhorar a comunicação entre estudantes, profissionais e setores institucionais.

A plataforma reúne, em um único ambiente, recursos para **solicitação de atendimentos, acompanhamento de protocolos, agendamentos, triagem digital orientativa, notificações, comunicação entre setores, informações institucionais e gerenciamento administrativo**.

---

## 🎯 Objetivo

O projeto busca tornar o acesso aos serviços de apoio do campus mais **simples, organizado e acessível**, reduzindo a necessidade de processos descentralizados e facilitando a comunicação entre a comunidade acadêmica e os setores responsáveis.

A plataforma foi pensada especialmente para:

* 👨‍🎓 Estudantes
* 👩‍🏫 Servidores
* 🏥 Profissionais de atendimento
* 🏫 Setores administrativos
* 👨‍💼 Gestores do campus

---

## ✨ Funcionalidades

### 🏠 Dashboard

O painel inicial apresenta uma visão geral da plataforma, incluindo:

* Quantidade de solicitações;
* Agendamentos;
* Notificações;
* Mensagens;
* Atendimentos disponíveis;
* Estatísticas de atendimentos;
* Últimos avisos do campus;
* Acessos rápidos aos principais serviços.

O dashboard também possui gráfico para visualização da distribuição das solicitações por área.

---

### 🏥 Serviços de Atendimento

O sistema disponibiliza **7 áreas de atendimento**:

1. Psicologia
2. Pedagogia
3. Serviço Social
4. Enfermagem
5. Coordenação Geral
6. Odontologia
7. Nutrição

Essas áreas estão integradas ao sistema de solicitações e à base de conhecimento da plataforma.

---

### 📩 Solicitação de Atendimento

O usuário pode criar uma nova solicitação informando:

* Área de atendimento;
* Assunto;
* Modalidade desejada;
* Descrição da demanda;
* Data de preferência;
* Curso ou setor no IFAL.

Após o envio, o sistema gera um **protocolo de atendimento**, permitindo acompanhar posteriormente a solicitação.

---

### 📋 Acompanhamento de Solicitações

O usuário pode consultar suas solicitações e acompanhar diferentes estados, como:

* Em análise;
* Em andamento;
* Atendida;
* Cancelada;
* Concluída;
* Agendada.

Também existe pesquisa por protocolo, atendimento ou descrição.

---

### 📅 Agendamentos

A plataforma permite realizar e consultar agendamentos.

O sistema verifica conflitos de horário para evitar que o mesmo profissional seja agendado para duas pessoas no mesmo horário.

Também é possível:

* Selecionar o serviço;
* Selecionar o profissional;
* Escolher data;
* Escolher horário;
* Consultar o local;
* Cancelar agendamento;
* Receber notificação de confirmação.

---

### 🧠 Triagem Digital Orientativa

O sistema possui uma **Triagem Digital Orientativa**, que direciona o usuário para o setor mais adequado de acordo com sua necessidade.

Exemplos:

* Apoio emocional → Psicologia;
* Dificuldades acadêmicas → Pedagogia;
* Auxílios estudantis → Serviço Social;
* Sinais vitais e curativos → Enfermagem.

A própria plataforma deixa claro que a triagem é **orientativa e não substitui avaliação profissional ou médica**.

---

### 🤖 Assistente de Informações

O sistema possui um assistente baseado na **base de conhecimento/FAQ cadastrada no sistema**.

Ele consegue responder perguntas relacionadas aos serviços, setores, funcionamento da plataforma e outras informações cadastradas.

O painel administrativo permite adicionar novas perguntas e respostas e ativar ou desativar itens da base de conhecimento.

---

### 📢 Mural de Avisos

O sistema possui um espaço para divulgação de:

* Comunicados;
* Informações institucionais;
* Avisos dos setores;
* Orientações sobre serviços.

Administradores podem publicar novos avisos diretamente pelo painel administrativo.

---

### 💬 Comunicação entre Setores

A plataforma possui um canal de comunicação intersetorial para facilitar a troca de mensagens entre o usuário e setores do campus.

Entre os destinos disponíveis estão:

* Coordenação Geral;
* Psicologia;
* Pedagogia;
* Serviço Social;
* Enfermagem;
* Odontologia;
* Nutrição.

---

### 📍 Unidades e Setores

A plataforma apresenta os locais de atendimento cadastrados no campus, com informações como:

* Nome do local;
* Localização;
* Horário;
* Serviços disponíveis.

O projeto possui, por exemplo, registros para o **Setor de Saúde e Apoio Acadêmico** e o **Consultório Odontológico Institucional**.

---

### ❓ Informações e FAQ

A área de informações reúne perguntas frequentes sobre:

* Como solicitar atendimento;
* Significado dos status;
* Como realizar agendamentos;
* Serviços disponíveis.

A base de FAQ também pode alimentar o assistente de informações.

---

### 🚨 Emergência

A plataforma possui uma área específica com orientações para situações de emergência.

São apresentados canais como:

* **SAMU — 192**
* **Corpo de Bombeiros — 193**

A área é destinada a situações que ultrapassam o suporte institucional do campus.

---

### 👤 Perfil do Usuário

Cada usuário possui uma área de perfil contendo informações como:

* Nome;
* E-mail institucional;
* Tipo de usuário;
* Telefone/WhatsApp;
* Curso ou setor.

---

### 🔔 Notificações

O sistema possui uma central de notificações para informar o usuário sobre acontecimentos relacionados à sua utilização da plataforma.

Entre os exemplos estão:

* Boas-vindas;
* Agendamentos confirmados;
* Atualizações de solicitações;
* Novos avisos.

---

### 🔐 Login e Cadastro

A plataforma possui sistema de autenticação com:

* Login;
* Cadastro;
* Logout;
* Controle de sessão;
* Diferenciação entre usuários e administradores;
* Proteção do painel administrativo.

Usuários cadastrados recebem a função padrão de **paciente**, enquanto administradores possuem acesso aos recursos administrativos.

O acesso ao painel administrativo é restrito a usuários com função de administrador.

---

## 🛡️ Painel Administrativo

O sistema possui um painel administrativo destinado aos gestores.

O painel permite gerenciar:

* 📋 Solicitações;
* 👥 Usuários;
* 👨‍⚕️ Profissionais;
* 🤖 Base de conhecimento da IA/FAQ.

### Gestão de solicitações

Administradores podem visualizar protocolos e alterar seus status.

As alterações também são registradas no histórico da solicitação.

### Gestão de usuários

O administrador consegue visualizar os usuários cadastrados e suas informações básicas.

### Gestão de profissionais

O painel apresenta profissionais cadastrados juntamente com suas respectivas especialidades e status.

### Gestão do conhecimento

Administradores podem cadastrar perguntas e respostas para ampliar a base de conhecimento utilizada pelo assistente da plataforma.

## 🧰 Tecnologias utilizadas

O projeto atual utiliza uma arquitetura baseada em **HTML, CSS e JavaScript**, com bibliotecas carregadas por CDN.

### Front-end

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* Font Awesome
* Chart.js
* Google Fonts — Inter

O código utiliza Tailwind CSS para estilização, Font Awesome para os ícones e Chart.js para os gráficos do dashboard.

### Armazenamento

Na versão atual do projeto, os dados são armazenados utilizando o **LocalStorage do navegador**.

O estado da aplicação é salvo com a chave:

`saude_conectada_ifal_2026_sec_v12`

> **Importante:** o LocalStorage é adequado para prototipagem e demonstração, mas uma versão institucional em produção deve utilizar um banco de dados e um backend seguros.

## 🔒 Segurança

A versão atual foi estruturada principalmente como **protótipo funcional/demonstração**.

Embora exista tratamento de senha e controle de acesso na interface, informações de autenticação e dados armazenados no navegador **não devem ser considerados suficientes para um sistema institucional real**.

Para produção, a autenticação e os dados dos usuários devem ser processados em um servidor seguro.
